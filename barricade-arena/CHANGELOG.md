# Release notes

## v4.0 — OMEGA

- Browse and join public waiting rooms without knowing an invite code, or create invite-only private rooms.
- Players' equipped passive loadouts and unspent item cards are visible using their individual card-inspection buttons. Opponent-specific draft choices and tokens stay hidden.
- 81 real cards, including new exceptionally powerful passive movement, wall economy, instant extra action, destructive wall removal, reset, steal and position-swap effects.
- Seven server-owned random event types, scheduled using a host-configurable interval, with motion-aware UI banners.
- Switchable central victory objective for four-player games. Hosts can switch back to edge goals during a game. Wall routes to the newly chosen central goal are repaired when necessary.
- Hosts can turn random events off/on during gameplay.
- Improved public lobby and player intel UI, animated CORE marker, event visuals and card sheen.
- 32 passing automated game-rule tests and simulated browser-flow checks.

## v3.0 — EVOLUTION

- Six selectable classes with mastery progression and server-validated skills.
- 58 cards, private lobbies, bots and particle effects.
